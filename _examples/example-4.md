<p>This example demonstrates how to build a custom integrator in PSCAD using Fortran code and EMTDC storage variables. The component integrates an input signal using a specified time constant, initial condition, and upper and lower output limits. </p>
<p>The implementation uses trapezoidal integration allowing its numerical behavior to match PSCAD’s Master Library integrator. It also demonstrates how previous time step values are stored and used within a custom PSCAD component. </p>
