<p>This example demonstrates a PSCAD custom component that exchanges data with an external Fortran routine. The component accepts a real value through an input port and an integer value through a component parameter.</p>
<p>The resulting real value is then returned to PSCAD through the custom component and plotted in the simulation.</p>
