# EMT-Tools: Free PSCAD Resources

Welcome to the official repository for **[EMT-Tools](https://www.emt-tools.com)**, a community driven platform dedicated to building the largest online collection of freely downloadable PSCAD examples, EMTDC models, and modern power system simulation resources. 

## 🌐 Platform Links

* **Main Website:** [www.emt-tools.com](https://www.emt-tools.com) — Browse, search, and download PSCAD cases, custom components, and engineering workflows.
* **Community Forum:** [forum.emt-tools.com](https://forum.emt-tools.com) — Ask technical questions, share simulation experiences, propose new ideas, and troubleshoot EMT problems with other power systems engineers.

## 📚 About the Collection

EMT-Tools hosts and indexes a wide variety of simulation assets, categorized into two main sections on the site:

* **Community Submissions:** Downloadable PSCAD cases built by the power systems community and EMT-Tools. These cases are reviewed by the maintainers to comply with our submission guidelines and are distributed under the MIT License.
* **External Resources:** A curated directory of links to third-party PSCAD models, tools, and papers. These are hosted externally and maintain their own independent licenses and credits.

## 🤝 How to Contribute

We welcome submissions from the global power systems community. Whether you have developed a custom component, a complex control implementation, or a detailed inverter-based resource (IBR) model, your contributions help engineers worldwide.

To submit a PSCAD case or add an external resource link:
1. Fork this repository.
2. Review our [Submission Guidelines](https://www.emt-tools.com/contribute/).
3. Add your resource details to `_data/submissions.yml` using the required template formatting (including Author names, Organization, and LinkedIn URLs).
4. Open a Pull Request using the provided PR template. 

*Security Note: All direct file submissions are processed through an automated quarantine pipeline and scanned via virus scanner tools prior to human review.*
